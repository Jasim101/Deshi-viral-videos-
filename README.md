# ফান হাব (Fun Hub) - টেলিগ্রাম মিনি অ্যাপ এবং ফুল কন্ট্রোল অ্যাডমিন প্যানেল

টেলিগ্রাম ওয়েবঅ্যাপ (Telegram Mini App) এবং রিয়েল-টাইম ভিডিও স্ট্রিমিং ও মনিটাইজেশন প্ল্যাটফর্ম।

---

## 🚀 কম্পিউটার বা নিজস্ব সার্ভারে যেভাবে চালাবেন (Quick Start)

### ১. প্রয়োজনীয় উপাদান (Prerequisites)
- [Node.js](https://nodejs.org/) (ভার্সন ১৮ বা তার বেশি)
- npm বা yarn বা bun

### ২. ডিপেন্ডেন্সি ইনস্টল করুন (Install Dependencies)
প্রোজেক্ট ফোল্ডারে টার্মিনাল বা কমান্ড প্রম্পট খুলে রান করুন:
```bash
npm install
```

### ৩. ডেভেলপমেন্ট মোডে চালানো (Development Mode)
```bash
npm run dev
```
এরপর ব্রাউজারে প্রবেশ করুন:
- **মিনি অ্যাপ / ভিডিও ভিউয়ার:** `http://localhost:3000`
- **অ্যাডমিন প্যানেল:** `http://localhost:3000/admin` (অথবা অ্যাপের নিচে তালার আইকন)

### ৪. প্রোডাকশন বিল্ড ও রান (Production Deployment)
```bash
npm run build
npm start
```

## 🔐 অ্যাডমিন সিকিউরিটি ও সেটিংস

1. **ডিফল্ট অ্যাডমিন পাসওয়ার্ড:** `admin123`
   - প্রথমবার লগইন করার পর সিকিউরিটি ট্যাব থেকে পাসওয়ার্ড পরিবর্তন করে নিন।
2. **টেলিগ্রাম আইডি লক:** 
   - আপনার টেলিগ্রাম আইডি (`6847071695`) দিয়ে লক কনফিগার করা আছে।
   - অন্য কেউ মিনি অ্যাপ ওপেন করলে তারা তালার আইকন বা অ্যাডমিন লগইন বক্স দেখতে পাবে না।
   - টেলিগ্রাম আইডি পরিবর্তন বা রিসেট করতে চাইলে `data/auth.json` ফাইলে `adminTelegramId` ফিল্ডটি এডিট করতে পারবেন।
3. **কনফিগারেশন ও আপলোডকৃত মিডিয়া:**
   - সমস্ত ভিডিও, ক্যাটাগরি, মেনু এবং থিম সেটিংস `data/config.json` ফাইলে সংরক্ষিত থাকে।
   - আপলোডকৃত ভিডিও এবং থাম্বনেইল ছবিগুলো `data/uploads/` ফোল্ডারে সংরক্ষিত থাকে।
